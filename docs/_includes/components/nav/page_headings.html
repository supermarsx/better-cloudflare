    ` of links to the *headings* of the page currently being rendered, or an empty string when there is nothing to list. `components/nav/links.html` nests it under that page's own entry in the main navigation, so a long page is navigable without scrolling it first. Depends on: content - the rendered HTML of the current page. This is set by the layout, so this include only works when it is reached from `_layouts/default.html`. site.nav_heading_level - deepest heading to list: 2 lists only `##` sections, 3 (the default) also nests `###` subsections under their section. site.nav_headings - set to false to switch the whole feature off. page.nav_headings - set to false in a page's front matter to switch it off for that page only. Why the headings are read back out of `content` rather than re-derived from the markdown: the `id` attributes are the ones kramdown actually generated, so every link here is guaranteed to hit a real anchor. Re-slugifying the heading text in Liquid would not match kramdown's algorithm (it strips leading non-letters and does not collapse runs of spaces, `slugify` does the reverse).
