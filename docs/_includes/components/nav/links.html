{%- comment -%} Overrides the theme's `components/nav/links.html` (just-the-docs v0.12.0). The only change from upstream: beneath the entry for the page you are currently on, the navigation also lists that page's own headings, via `components/nav/page_headings.html`. Everything else — the recursion over child pages, the duplicate-title error report, the expander markup — is the stock include, so a theme bump can be reconciled by diffing against it. Two things this override relies on: * `content` is in scope. `components/sidebar.html` is overridden alongside this file to include the site nav uncached, because the nav is no longer the same on every page. * The heading list is skipped when `all` is true. `components/children_nav.html` renders the nav with `all=true` and then string-matches it to decide whether a page has child pages; leaving the heading list out of that pass keeps the check looking at exactly the markup upstream expects. Include as: {%- include components/nav/links.html pages=page_array ancestors=title_array all=bool -%} Depends on: include.pages, include.ancestors, include.all. Results in: HTML for the main navigation when all is nil or false; includes links to pages excluded from the main navigation when all is true. Includes: components/nav/sorted.html, components/nav/children.html, components/nav/page_headings.html, components/nav/links.html. Overwrites: node, nav_children, nav_ancestors, nav_current, nav_expandable, and everything listed in components/nav/page_headings.html. {%- endcomment -%}
