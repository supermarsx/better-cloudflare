{%- comment -%} Overrides the theme's `components/sidebar.html` (just-the-docs v0.12.0). The only change from upstream: the main navigation is included with `include` rather than `include_cached`. `components/nav/links.html` is overridden to list the current page's headings beneath its own entry, so the nav differs from page to page and a cached copy would show every page the headings of whichever page happened to render first. This site has nine pages, so rendering the nav once per page costs nothing worth measuring. `components/children_nav.html` still renders the nav through `include_cached` (with `all=true`), and that copy is still page-independent, because the heading list is skipped whenever `all` is true.
